# Demo Project — учебная память Reviewer

> Синтетический пример. Эта папка показывает форму памяти и не создаёт привязку к реальному проекту или чату.

Идентификатор учебного проекта: `demo-project`.

Название: Demo Project — сервис уведомлений.

## Привязки и источники

- Учебная конфигурация: [repository/src/config.py](repository/src/config.py).
- Принятые в сценарии решения: [DECISIONS.md](DECISIONS.md).
- Образец заключения: [REVIEW.md](REVIEW.md).
- Реальный репозиторий и чат Command Center в примере не используются.

## Цель и рабочая модель

Сервис уведомлений должен ограничивать ожидание ответа внешнего провайдера. В учебной постановке выбран тайм-аут одного запроса 10 секунд; значение хранится в явной константе конфигурации.

## Принятые решения

- D-001: тайм-аут одного запроса — 10 секунд.
- D-002: выбранное значение задаётся явной константой `REQUEST_TIMEOUT_SECONDS`.

Основания и границы решений находятся в [DECISIONS.md](DECISIONS.md).

## Текущая позиция

Конфигурация подготовлена к проверке. Вопрос пользователя: «Соответствует ли значение тайм-аута принятому решению?»

Следующему сеансу достаточно сопоставить D-001 и показанную конфигурацию. Для ответа на этот вопрос весь репозиторий или история обсуждений не нужны.
