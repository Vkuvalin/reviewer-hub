# Demo Project — принятые решения

> Учебная постановка для примера Reviewer Hub.

## D-001. Тайм-аут одного запроса

**Принято в сценарии:** ожидание ответа внешнего провайдера ограничивается **10 секундами** на один запрос.

Цель — не оставлять пользователя в длительном ожидании ответа.

## D-002. Явная настройка

**Принято в сценарии:** выбранное значение хранится в константе `REQUEST_TIMEOUT_SECONDS`.

Для этого примера проверяется соответствие значения константы решению D-001. Сетевые вызовы и поведение работающего сервиса в учебный набор не входят.
