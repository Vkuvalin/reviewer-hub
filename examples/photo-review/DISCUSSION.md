# Обсуждение: можно ли сохранять оценки по одной?

Учебная постановка, восстановленная по сохранённому разбору.

**Пользователь:** загружены три фотографии предмета. AI вернул список оценок. Предлагается пройти по ответу, найти фотографию по `photo_id` и сразу сохранить качество. Если строк три, весь набор обработан. Достаточно ли этого?

**Command Center:** backend владеет составом отправленных фотографий. Проверка качества относится к конкретному запросу; модель оценивает переданные снимки.

**Вопрос Reviewer:** где до первой записи проверяется, что ответ содержит каждую ожидаемую фотографию ровно один раз?

## Принятый контракт

1. Ожидаемый набор текущего запроса — `front, back, mark`.
2. Каждому ID соответствует ровно одна оценка.
3. Пропуски, повторы и посторонние ID делают весь ответ невалидным.
4. При невалидном ответе обработчик не вызывает запись результатов.
5. Корректный ответ может перечислять фотографии в другом порядке: сопоставление выполняется по ID.

## Предложение команды к проверке

К текущему поэлементному обработчику добавить проверку количества строк и считать её достаточной проверкой полноты. Сопоставление по `photo_id` сохранить.

Reviewer должна проверить именно это предложение по [обработчику](repository/quality.py). Перестройка всей системы, новый формат хранения и исследование качества модели в этот вопрос не входят.
