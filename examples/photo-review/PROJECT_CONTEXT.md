# Сервис описания предметов — память Reviewer

Status: Reviewer-owned derived context, non-canonical.

Это учебная память кейса; она не создаёт активной привязки к реальному проекту или чату.

Идентификатор примера: `photo-review`.

## Цель

Проверить, можно ли применять AI-оценки фотографий по одной до проверки всего ответа.

Сервис получает три снимка предмета. Backend задаёт ожидаемый набор ID, модель возвращает оценки качества.

## Точка продолжения

Сопоставление по `photo_id` уже предусмотрено. Неясно, гарантирует ли обработчик полноту, уникальность и принадлежность ID текущему набору до первой записи.

Достаточно проверить контракт и две функции: `apply_sequentially` и `apply_after_validation`. Ответ с тремя строками сам по себе не доказывает полноту набора.
